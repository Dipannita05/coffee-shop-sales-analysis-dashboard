# ☕ Coffee Shop Sales Analysis Dashboard

## 📌 Project Overview

This project showcases an interactive **Coffee Shop Sales Analysis Dashboard developed using Microsoft Power BI**. The dashboard was created as a personal learning project driven by an interest in coffee, data analysis, and visually appealing dashboard design.

The dashboard provides insights into coffee shop sales performance, customer footfall, product preferences, ordering patterns, and store-wise performance through interactive visualizations and key performance indicators.

## 🎯 Project Objectives

- Analyze overall coffee shop sales performance using Power BI.
- Monitor key business metrics such as total sales, footfall, and average customer spending.
- Identify hourly ordering patterns and peak business hours.
- Compare sales performance across product categories and product sizes.
- Analyze store-wise sales and customer footfall.
- Identify top-performing products and weekday ordering trends.
- Develop an interactive and visually organized sales dashboard.

## 📊 Dashboard Features

The dashboard enables users to analyze:

- **Key Performance Indicators:** Total Sales, Total Footfall, Average Bill per Person, and Average Orders per Person.
- **Quantity Ordered by Hour:** Analyze hourly order volumes and identify peak ordering periods.
- **Category-wise Sales Distribution:** Understand the contribution of different product categories to overall sales.
- **Order Size Distribution:** Examine customer preferences across different product sizes.
- **Store-wise Performance:** Compare sales and footfall across store locations.
- **Top 5 Products:** Identify the best-performing products based on sales.
- **Weekday Ordering Trends:** Analyze variations in customer ordering activity across weekdays.

Interactive Month and Day filters allow users to explore sales performance across different time periods.

These fields support the analysis of sales trends, product performance, customer ordering patterns, and store-level activity.
